# SFX library — sources and licences

Every file here is published as **CC0 1.0** (public domain): free to use in videos,
including monetized ones, with no attribution required. It is fetched from GitHub
because stock sites (Pixabay, Freesound, Mixkit) are blocked in the cloud container.

## Pack 1: from `asaf5767/reelkit` (skills/reelkit/assets/sfx)

Licence texts are in `licenses/`. Sources:
- Kenney: Interface Sounds, Impact Sounds, UI Audio
- OpenGameArt: Swishes Sound Pack
- Freesound #685256 (riser)

| file | use for |
| --- | --- |
| `whoosh`, `whoosh-short`, `whoosh-cinematic` | short swishes on cuts or text entries (0.10–0.23 s) |
| `riser` | 1.5 s build into a reveal; it peaks at its end |
| `impact-bass-1`, `impact-bass-2` | low hit on a callout or number |
| `pop`, `click`, `click-soft`, `ping`, `chime`, `sparkle`, `notification`, `key-press`, `error` | UI-style accents |
| `glitch-1..3` | micro glitch stabs (≈0.05 s) |

## Pack 2: from `lavenderdotpet/CC0-Public-Domain-Sounds`

That repository is a collection of CC0 packs; the original pack folders are named in the table. Every file here was peak-normalized to −1 dBFS, 48 kHz.

| file | source in that repo | use for |
| --- | --- | --- |
| `boom-cannon` | 25-CC0-bang-sfx/cannon_02 | deep cinematic boom on a reveal |
| `explosion-1` | 100-CC0-SFX/explosion | short explosion punch |
| `explosion-2` | 50-cc0-sci-fi-sfx/explosion_01 | sci-fi blast, longer tail |
| `explosion-3` | 50-cc0-sci-fi-sfx/explosion_02 | sci-fi blast |
| `thunder` | 100-cc0-sfx-2/thunder_01 | 5.3 s rumble: tension bed or lightning scenes |
| `hit-heavy` | 75-cc0-breaking-falling-hit-sfx/bfh1_hit_02 | heavy body hit |
| `hit-punch` | 100-CC0-SFX/hit_04 | punch on text slams |
| `bang` | 25-CC0-bang-sfx/bang_06 | gunshot-like bang (GTA) |
| `swish-1..4`, `slash` | Micro Pack - Organic Wooshes | organic whooshes on transitions |
| `whoosh-combo`, `whoosh-twirl` | Micro Pack - Organic Wooshes | longer whooshes into a scene change |

Before adding anything new, re-check the licence on the source. A pack listed with several licences (e.g. CC0 *and* CC-BY-SA) is not clean CC0.
